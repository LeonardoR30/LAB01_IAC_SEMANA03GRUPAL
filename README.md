# LAB01_IAC_SEMANA03GRUPAL

## Descripción del proyecto

en este laboratorio implementamos una infraestructura como codigo con Terraform y Docker.

 permite crear y administrar contenedores Docker mediante Terraform, utilizando imágenes oficiales de Nginx, Node.js y PostgreSQL.

El ambiente desarrollado corresponde a DEV, donde se despliegan los servicios de frontend, backend y base de datos.

---

## Tecnologías utilizadas

 Terraform 
 Docker
 Provider Docker de Terraform (kreuzwerker/docker)
 Nginx
 Node.js
 PostgreSQL
 GitHub Codespaces
